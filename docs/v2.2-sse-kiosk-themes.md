# 🌐 Project Jarvis v2.2 — Realtime SSE, Kiosk Mode & Цветовые темы

Дата: 31.10.2026

## 🚀 Что нового в версии 2.2:

### 1. ⚡ Server-Sent Events (SSE Realtime Push)
- **Убран постоянный HTTP-опрос (`fetch` каждые 3 секунды):** браузер больше не засыпает ESP32 бесконечными запросами.
- **Потоковый эндпоинт `/api/events`:** ESP32 удерживает лёгкое постоянное соединение и сам мгновенно отправляет обновлённый JSON в браузер через нативный `EventSource`.
- Снижена нагрузка на CPU и сеть, реакция интерфейса на сохранение настроек теперь мгновенная.
- При потере связи браузер автоматически переподключается с плавным фоллбеком.

### 2. 📺 Полноэкранный Kiosk Mode («Настенный Дашборд»)
- Кнопка с иконкой полноэкранного режима в шапке (рядом с выбором тем).
- Разворачивает минималистичный эстетичный экран на весь монитор/планшет/телефон:
  - **Огромный циферблат часов** с секундами (синхронизирован по NTP).
  - Крупные цифры температуры и влажности (видны через всю комнату).
  - Строки «Ощущается как» и «Точка росы» с текстовым статусом.
  - Бейдж текущего режима (День/Ночь) и процент яркости.
- Поддерживает системный Fullscreen API (скрывает строку браузера на Android/iOS/Windows).
- Выход — клик в любое место или клавиша `Esc`.

### 3. 🎨 4 стильные цветовые темы (с сохранением в LocalStorage)
- **🌙 Midnight Slate** (по умолчанию): глубокий графитовый фон `#090a0d`, акцентный циан `#38bdf8`, мягкие тени.
- **🖤 OLED True Black**: абсолютно чёрный `#000000` фон — идеален для AMOLED экранов (нулевой расход батареи планшета/телефона и бесконечный контраст).
- **⚡ Cyberpunk Neon**: неоновый фиолетовый `#0b0717` + ядовито-розовый и бирюзовый `#00f0ff` акценты.
- **☀️ Pastel Clean**: светлая минималистичная тема для ярких дневных комнат.
- Тема сохраняется в браузере и динамически переключает системный `theme-color` строки состояния телефона.
