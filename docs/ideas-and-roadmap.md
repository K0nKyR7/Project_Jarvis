# 🚀 Идеи по дальнейшему развитию Project Jarvis

Здесь собраны предложения по улучшению проекта, разбитые по направлениям и уровню сложности/пользы.

---

## 1. 🧠 Умные фичи и автоматизация (Software / Features)

### 🌡️ Расчёт индекса комфорта и точки росы (Dew Point / Heat Index)
- Одной лишь температуры и относительной влажности мало для оценки реального комфорта человека.
- **Что добавить:**
  - Расчёт **Heat Index** («Ощущается как...») по формулам NOAA.
  - Расчёт **Точки росы** (Dew point) — показатель духоты в помещении.
  - Расчёт **Абсолютной влажности** (г/м³) — чтобы понимать, насколько на самом деле сухой воздух зимой при работающем отоплении.

### ⏰ Тихий час (Night Mode)
- Сейчас алерты Telegram и свечение RGB LED работают 24/7.
- **Что добавить:**
  - Синхронизацию времени по **NTP** (`pool.ntp.org`).
  - Ночной режим (например, с 23:00 до 08:00): приглушение или полное отключение светодиода, отключение звуковых уведомлений или временный мьют несрочных алертов.

### 📈 Прогнозирование тренда (Куда движется климат?)
- По истории точек можно определять производную (скорость изменения):
  - *"Температура падает со скоростью 1.5°C/ч (открыто окно?)"*
  - *"Влажность резко растёт (+15% за 10 мин) — вероятно, включили душ/начали готовить"*.

## 2. 🏠 Интеграция в Умный Дом (Ecosystem)

### 📡 MQTT + Home Assistant / Apple HomeKit
- Простой встроенный веб-сервер удобен, но если захочется автоматизировать технику (включать розетку увлажнителя или кондиционер):
  - Добавить **MQTT клиент** (библиотека `PubSubClient`).
  - Настроить **Home Assistant Auto-Discovery** — ESP32 автоматически появится в Home Assistant со всеми сенсорами без ручной настройки YAML.

### 🌐 Prometheus / Grafana метрики
- Добавить эндпоинт `/metrics` в формате OpenMetrics/Prometheus.
- Позволит строить красивые графики за месяцы/годы в Grafana без нагрузки на память самого ESP32.

## 3. 🔌 Аппаратные улучшения (Hardware)

### 💎 Замена DHT11 на прецизионный сенсор (I2C)
- **DHT11** — датчик начального уровня (погрешность по температуре ±2°C, по влажности ±5%, диапазон влажности всего 20–90%).
- **Альтернативы:**
  - **AHT20 / AHT21** или **SHT30 / SHT31** (интерфейс I2C): точность ±0.2°C и ±2% влажности, мгновенный отклик, высочайшая стабильность.
  - **BME280**: помимо температуры и влажности выдаёт **атмосферное давление** (можно отслеживать изменения погоды и прогнозировать осадки/головные боли метеозависимых).

### 🖥️ Маленький локальный дисплей
- Добавить недорогой экран:
  - **OLED 0.96" SSD1306** (I2C) — компактно, стильно, видно текущие показатели без открытия телефона.
  - Или **E-Paper (электронные чернила)** 1.54" / 2.13" — не слепит ночью, выглядит как премиальный гаджет.

### 🔊 Пьезопищалка (Buzzer)
- Короткий тихий «бип» при превышении критических значений или включении устройства.

## 4. 📱 Улучшение Веб-интерфейса (UI / UX)

### 🎨 Кастомизация интерфейса
- Добавление переключателя темы (Light / Dark / OLED True Black).
- Возможность вручную менять яркость светодиода слайдером прямо из веб-панели (ползунок яркости 0–100%).
- Кнопка «Принудительная калибровка/смещение» (Offset) для температуры и влажности (если датчик врёт на 1–2 градуса из-за нагрева платы).

### 📥 Экспорт данных (CSV)
- Эндпоинт `/api/export.csv` для выгрузки накопленной истории точек в Excel / Google Таблицы.

---

## 5. 🔒 Безопасность и отказоустойчивость

### 🔑 Авторизация веб-интерфейса
- Простой HTTP Basic Auth на критические эндпоинты (`/api/save`, `/update`).

### 📶 Режим точки доступа при первом старте (WiFiManager)
- Если домашний роутер сменил пароль или имя сети, ESP32 сейчас уходит в рестарт.
- Библиотека **WiFiManager** (или самописный Captive Portal): если не удалось подключиться за 60 секунд, ESP32 поднимает свою сеть `Jarvis-Setup`, открывает страницу входа и даёт ввести новый Wi-Fi без перепрошивки по проводу.

## Рекомендуемый порядок внедрения

| Приоритет | Фича | Что даст |
|---|---|---|
| **Этап 1** (Быстро, в коде) | **NTP время + Ночной режим** | Диод не светит ночью, точные таймстампы |
| **Этап 2** (Быстро, в коде) | **Расчёт точки росы / комфорта** | Реальная оценка духоты/климата |
| **Этап 3** (В коде) | **MQTT / Home Assistant** | Включение увлажнителей и розеток |
| **Этап 4** (Железо) | **BME280 / SHT30** | Качественные показания + давление |
